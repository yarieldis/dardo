# Dardo

REST API built with [Dart Frog](https://dartfrog.vgv.dev).

## Getting started

```bash
# Install dependencies
dart pub get

# Start dev server (hot reload enabled)
dart_frog dev
```

The server runs on `http://localhost:8080`.

## Project layout

```
routes/          # API endpoints (file-based routing)
test/            # Tests
```
